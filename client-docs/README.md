# Respace Site — Client Change Guide

Welcome! This folder contains everything you need to update your website without any technical knowledge.

---

## First Time Here?

**[Start with the Setup Guide](00-setup-guide.md)** — it walks you through installing everything and getting the site files on your computer. You only do this once.

---

## How It Works

1. **Find the doc** for the section you want to change (list below)
2. **Fill in your new content** where you see `[BRACKETS LIKE THIS]`
3. **Copy the prompt** from that doc
4. **Paste it into Claude Code** — the change is applied automatically
5. **Commit and sync** in VS Code — the site goes live in ~2 minutes

That's it. No coding required.

## Tips

- **Only change what's inside the brackets.** Leave the surrounding text exactly as written.
- **You can make multiple changes at once** — just fill in all the blanks in a single doc before copying.
- **If something looks wrong after applying**, just run the prompt again with the corrected content.
- Each doc shows a **filled-in example** at the bottom so you can see what it looks like when done correctly.
